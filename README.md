## Заметки и полезные приёмы

### Форматирование чисел (f-строки)
- `:.2f` — выводит число с 2 знаками после точки
- используется для денег, процентов, дробных чисел

Пример:
```python
price = 100
print(f"Цена с НДС: {price * 1.2:.2f}")
```
### input() всегда возвращает строку
для чисел нужно int() или float()

Пример:
```python
age = int(input("Введите возраст: "))
```
