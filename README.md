## Заметки и полезные приёмы

### Форматирование чисел (f-строки)
- `:.2f` — выводит число с 2 знаками после точки
- используется для денег, процентов, дробных чисел

Пример:
```python
price = 100
print(f"Цена с НДС: {price * 1.2:.2f}")
```
### input() всегда возвращает строку
для чисел нужно int() или float()

Пример:
```python
age = int(input("Введите возраст: "))
```
### Удаление переменной
del test # удалили переменную test

### Присвоение типа данных переменной
Важность совпадения типов данных при присвоении переменных. Присвоение типа данных, например str(age) - присвоили переменной age тип string

### Математические операции
- Символ для возведения в степень: две звёздочки `**`. Пример: `5 ** 2` = 25
- Символ для целочисленного частного: двойной слэш `//`. Пример: `20 // 6` = 3 (сколько целых чисел 6 в числе 20)
- Символ для деления по модулю: процент `%`. Пример: `20 % 6` = 2 (сколько остается после всех целых делений на 6)

### Условия
- if = проверка условия (если)
- elif = проверка альтернативного условия, только если предыдущие if/elif не сработали (иначеЕсли)
- else = выполняется, если ни одно из условий выше не сработало (иначе)

Пример:
```python
age = int(input("Введите ваш возраст: "))

if age < 7:
    print("Вы малыш")
elif age < 18:
    print("Вы подросток")
elif age < 60:
    print("Вы взрослый")
else:
    print("Вы пожилой человек")
```
```python
num = 1
if num:     #- Данное выражение возвращает True, так как переменная num не пустая
```

### Списки

#### Написание
```Python
test = [1, 2, 3, 4, 5]  # - Список
print (test[4])         # - Результат вывода - "3", так как элементы считаются с 0, в этом списке число 1 это элемент под номером 0
```
#### Списки в списках
```Python
test = [1, 2, 3, 4, [5, 6, 7]]  # - Список с подсписком
print (test[4][1])              # - Результат вывода - "6",  [4] - это номер в первом списке, [1] - номер в подсписке
```
#### "in" и "not in"
```Python
test = [1, 2, 3, 4, 5]  # - Список
if 4 in test:           # - Если в списке есть "4", то выполнить следующее условие
    print("В списке test есть число 4")
if 6 not in test:       # - Если в списке нет "6", то выполнить следующее условие
    print("В списке test нет числа 6")
```
#### Методы .append, .insert, .reverse и удаление через .remove,
```Python
test = [] -             # - создал пустой список с названием "test"
test.append(25)         # - добавил в список "test" значение "25"

```

### Собственные функции
```Python
def spam():                 # - создали свою функцию с названием "spam"
    print("spam")           # - тело функции

    print("spam")

spam()                      # - вызов своей функции, вывод будет "spam" 3 раза
```

```Python

multiply(4)                 # - "8"

```
#### Функция которая возвращает значение (return)
```Python
def max(x, y)               # - создали функцию с параметрами x и y, то есть при её вызове нужно будет ввести 2 аргумента
    if x > y:               # - условие функции
        return x            # - возвращаем результат
    else:
        return y            # - возращаем результат
print(max(5, 10))           # - выводим функцию на экран с агрументами 5 и 10, вывод "10"
```
