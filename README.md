### Исключения try, except
Исключения нужны для того, что бы программа не завершалась с ошибкой (исключением), если она присутствует
SyntaxError поймать НЕЛЬЗЯ!
Исключения ловятся по порядку, если мы поймали деление на ноль в первом except, то дальше проверка исключений уже не пойдет
Пример:
```Python
try:                                # - запуск контроля проверки исключений
    print (7 / 0)                   # - что мы проверяем, программа проверяет это условие, если оно выполняется, то блок завершен, если нет, то переход к except
except ZeroDivisionError:           # - что мы делаем если исключение появилось, указываем какое именно исключение ловим, 
    print("Поймано исключение ДелениеНаНоль")     # - выводим на экран строку, можно написать просто "pass" для пропуска без каких то действий
except NameError:
    print("Поймано исключение НеизвестнаяПеременная")
except:                             # - если оставить просто except, то ловим все исключения
    print("Поймано какое то другое исключение по мимо ДелитьНаНоль")
finally:
    print("Поимка исключений завершена")    # - можно добавить, исполняется всегда, даже если исключений не было поймано
```
Так же можно прописать все перехватываемые исключения в одну строку
```Python
except(ZeroDivisionError, NameError, ValueError):
    ...
```

Создание своего исключения:
```Python
if number == 0:                     # - условие исключения
    raise NameError                 # - создали исключение с именем NameError
```

#### Файлы, работа с ними

функция для работы с файлом - open
В функции open 2 аргумента, 1й - название файла, второй что требуется сделать с файлом, есть 4 основных варианта кторого аргумента:

Ниже программа по чтению файла с названием
