### Математические операции
- Символ для возведения в степень: две звёздочки `**`. Пример: `5 ** 2` = 25
- Символ для целочисленного частного: двойной слэш `//`. Пример: `20 // 6` = 3 (сколько целых чисел 6 в числе 20)
- Символ для деления по модулю: процент `%`. Пример: `20 % 6` = 2 (сколько остается после всех целых делений на 6)

### Условия
- if = проверка условия (если)
- elif = проверка альтернативного условия, только если предыдущие if/elif не сработали (иначеЕсли)
- else = выполняется, если ни одно из условий выше не сработало (иначе)

Пример:
```python
age = int(input("Введите ваш возраст: "))

if age < 7:
    print("Вы малыш")
elif age < 18:
    print("Вы подросток")
elif age < 60:
    print("Вы взрослый")
else:
    print("Вы пожилой человек")
```


### Исключения
Исключения нужны для того, что бы программа не завершалась с ошибкой (исключением), если она присутствует
SyntaxError поймать НЕЛЬЗЯ!
Исключения ловятся по порядку, если мы поймали деление на ноль в первом except, то дальше проверка исключений уже не пойдет
Пример:
```Python
try:                                # - запуск контроля проверки исключений
    print (7 / 0)                   # - что мы проверяем, программа проверяет это условие, если оно выполняется, то блок завершен, если нет, то переход к except
except ZeroDivisionError:           # - что мы делаем если исключение появилось, указываем какое именно исключение ловим, 
    print("Поймано исключение ДелениеНаНоль")     # - выводим на экран строку, можно написать просто "pass" для пропуска без каких то действий
except NameError:
    print("Поймано исключение НеизвестнаяПеременная")
except:                             # - если оставить просто except, то ловим все исключения
    print("Поймано какое то другое исключение по мимо ДелитьНаНоль")
finally:
    print("Поимка исключений завершена")    # - можно добавить, исполняется всегда, даже если исключений не было поймано
```
Так же можно прописать все перехватываемые исключения в одну строку
```Python
except(ZeroDivisionError, NameError, ValueError):
    ...
```

Создание своего исключения:
```Python
if number == 0:                     # - условие исключения
    raise NameError                 # - создали исключение с именем NameError
```

#### Файлы, работа с ними

функция для работы с файлом - open
В функции open 2 аргумента, 1й - название файла, второй что требуется сделать с файлом, есть 4 основных варианта кторого аргумента:
- r - чтение файла
- w - перезапись файла
- a - добавление в файл
- b - binary mode
- with - выполнение без открытия файла

Ниже программа по чтению файла с названием 
read (r)
```Python
file = open("test.txt", "r")    # - создали переменную file, внутри функция open с аргументами, то есть читаем файл test.txt
print(file.read())              # - выводим содержимое файла на экран (перед точкой что читаем, после точки функция read)
file.close()                    # - закрываем файл после работы с ним
```
write (w)
```Python
file = open("test.txt, "w"")    # - перезаписываем файл test.txt, если его не существует, он создастся
file.write("Привет, Мир!")      # - file.write описывает, что мы хотим записать в файл. Записали в файл текст "Привет, Мир!"
file.close()
```

append (a)
```Python
file = open("test.txt", "a")    # - 
print(file.write("test"))       # - добавили строку test
file.close()                    # - закрываем файл после работы с ним
```

binary (rb, wb, или ab) - данный метод используется для работы с другими типами файлов по мимо текстовых, картинки, музыка видео и тд.
```Python
file = open("test.txt", "rb")
```
