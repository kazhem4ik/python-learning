Важность совпадения типов данных при присвоении переменных. Присвоение типа данных, например str(age) - присвоили переменной age тип string
Символ для возведения в степень: две звёздочки `**`. Пример: `5 ** 2` = 25
Символ для частного: двойной слэш `//`. Пример: `20 // 6` = 3 (сколько целых чисел 6 в числе 20)
Символ для деления по модулю: процент `%`. Пример: `20 % 6` = 2 (сколько остается после всех целых делений на 6)
