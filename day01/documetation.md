git clone https://github.com/ТВОЙ_НИК/python-learning   - добавить папку с github на ПК
git status                                              - просмотр изменений
git add .                                               - Возьми ВСЁ, что изменилось в этой папке, и подготовь к сохранению
git commit -m "Day 1: первый код"                       - Создаёт снимок состояния проекта в этот момент.
git push                                                - отправляет изменения в GitHub 

git checkout c6ac0ca -- day01/day01.py                  - вернуть файл в папку с github (git checkout <hash> -- <file>)
